# Portafolio — Ignacio Gómez Miño

Portafolio estático hecho con HTML y CSS, con Bootstrap y Font Awesome cargados desde CDN.

## Archivos
- `index.html`: contenido del portafolio.
- `estilos.css`: estilos y adaptación a pantallas móviles.

## Publicarlo gratis con GitHub Pages
1. Creá un repositorio nuevo en GitHub llamado `portfolio` o `portafolio`.
2. Subí `index.html` y `estilos.css` a la raíz del repositorio.
3. En GitHub, abrí **Settings → Pages**.
4. En **Build and deployment**, seleccioná **Deploy from a branch**.
5. Elegí la rama `main` y la carpeta `/(root)`, luego guardá.
6. Esperá a que GitHub publique el sitio. La URL normalmente será `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.
